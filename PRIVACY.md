# VSQuote privacy

VSQuote does not collect telemetry, create accounts, load remote quote data,
or send usage information to the publisher or any third party.

All quote text ships inside the extension. Recent quote history stays in
memory for the current VS Code session. Favorites and the first-run selection
flag use VS Code's extension global state. VSQuote does not read or write
workspace files.

Copying a quote writes only the selected quote and attribution to the system
clipboard. VS Code and the Visual Studio Marketplace remain subject to
Microsoft's own privacy terms.
